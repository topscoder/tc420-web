  1. "My programs" is the library in this browser. The badge shows which program is on the controller; by default that is the only program on it.
  2. Send sends the selected program and replaces everything on the controller. Switching season = select ZOMER and send.
  3. Name strictly 8 characters (A–Z, 0–9, space, -) because the controller display shows it.
  4. Chart is the main editing surface (drag points); the table is the precise alternative.
  5. "Same level for all channels" is on for new programs; turning it off shows one slider per channel and per-channel Fade/Instant.
  6. Send is the one primary action, pinned under the list. If the program changed after sending, the hint says "WINTER changed since it was sent".

Send WINTER to the TC420?

The controller will run WINTER (9 steps). Everything else on the controller is removed.

The controller cannot be read back. Your programs stay saved in this browser; export a backup to be safe.

Also set the clock to 10:42
CancelSend
  1. Default: clear the controller, write the selected program to slot 1, set the clock. No program switching needed on the device.
  2. In "Multiple programs" mode the dialog lists "Program 1 ← WINTER, Program 2 ← ZOMER" and sends all.
  3. Says exactly what changes and why a backup matters.
  4. If not connected, clicking Send first runs the connect flow, then shows this dialog.
